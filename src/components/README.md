React UI components (`.tsx`) — Tailwind CSS and lucide-react. They call the engine (`src/core/`) directly and hold no naming rules.

- **Routes** (D57) — `main.tsx` draws one of `App` (the wizard at `/`, the four-step tree at `/pick`), `NamingDoc` (`/docs/naming`), `ApiDoc` (`/docs/api`, D98), `Privacy` (`/privacy`) or `About` (`/about`, D109) from `routeOf(location.pathname)` in `route.ts`, and `NotFound` for any other path (D106). `route.ts` re-exports the route table in `src/site/pages.ts`, which the Worker also uses, and `main.tsx` sets `document.title` from it. There is no router dependency. The naming guide draws a model that pure functions in `namingDocModel.ts` build from the generated catalog, the region table, the dictionary and the version — no hand-written numbers or tables. The API guide fetches `/openapi.json` from the same origin when it opens and builds its endpoint table, curl examples (the spec's request examples, with the page's origin as host) and trimmed responses in `apiDocModel.ts`
- **Share hash v3** (D55 · `urlState.ts`) — the region code (a zone input is stored as its region code — D50 revised) · an `r` value of `n` or `"n:kindName"`. The cap `MAX_HASH_CHARS` is a fixed formula measured by `urlState.test`. A link for a provider that is not enabled keeps the three free fields and `env`, drops the region and the selection, and says so in one line
- **A tree row is a catalog row** (D53 · `selection.ts` · `ResourceTree.tsx`) — a row with more than one rule picks the scope first, and kinds are filtered again by that scope's `allowed`.
- **Intro example** (D107) — the wizard's intro shows names read from `introExamples.json`, which `scripts/gen-intro-examples.mjs` writes before every build by calling the engine through `introExampleModel.ts` (the same path as the wizard); `introExamples.test.ts` fails when the committed file differs from the engine's output or any name is not `valid: true`. The UI never names anything itself
- **First-visit example** (D108 · `wizardSample.ts`) — with no hash the wizard starts from `samplePlan()` (four example values, the network prefill and the `serverless-web` card added with `addBundle`); the intro example is built from the same plan. On `/aws` it is `samplePlan('aws')`: the AWS example values and the `website` card (D141), 15 names. `Wizard.tsx` keeps a `sample` flag: while it is set the hash, Share URL and Save plan stay off and the Project panel shows **Example** and **Clear** (back to `startPlan()`, D97). Every change clears it. `wizardSample.test.ts` asserts every name is `valid: true`
- **Names bar** (D108) — tablet and phone only: a bar fixed at the bottom opens the Names drawer (tablet) or the Names tab (phone) and hides while they are shown. On a phone it shows the short label *View N names* (D109); `aria-label` is always the long label with the PASS count
- **About page** (D109 · `About.tsx` · `aboutModel.ts`) — `/about` on the `DocPage` frame: the intro's `IntroExample`, the same `pass_meaning` · `wizard_nothing_created` sentences as the names column, the source repository link (`SOURCE_REPOSITORY_URL`, the only place the URL is written), licence, status and `VERSION`. The More menu's About is a link to it (`aboutHref`), and `DocPage`, `App` and `Wizard` footers link to it next to Privacy
- UI text comes only from `src/messages/en.ts` — `no-hangul.test.ts` counts literals and JSX text

## 한국어

React UI 컴포넌트(`.tsx`) — Tailwind CSS · lucide-react 를 쓴다. 엔진(`src/core/`)을 직접 부르고 이름 규칙을 여기에 두지 않는다.

- **경로** (D57) — `main.tsx` 가 `route.ts` 의 `routeOf(location.pathname)` 로 `App`(네 단계) · `NamingDoc`(`/docs/naming`) · `ApiDoc`(`/docs/api`, D98) · `Privacy`(`/privacy`) · `About`(`/about`, D109) 중 하나를, 그 밖의 경로면 `NotFound` 를 그린다(D106). `route.ts` 는 Worker 도 쓰는 `src/site/pages.ts` 의 경로 표를 다시 내보내고, `main.tsx` 가 거기서 `document.title` 을 넣는다. 라우터 의존성은 없다. 이름 안내는 `namingDocModel.ts` 의 순수 함수가 생성 catalog · 지역 표 · 사전 · 버전에서 만든 모델을 그린다 — 손으로 쓴 숫자 · 표가 없다. API 안내는 열 때 같은 출처의 `/openapi.json` 을 받아 `apiDocModel.ts` 가 엔드포인트 표 · curl 예제(명세의 request example · 호스트는 페이지 origin) · 응답 일부를 만든다
- **공유 hash v3** (D55 · `urlState.ts`) — 지역 입력 코드(존이면 존 코드) · `r` 값 `n` 또는 `"n:값이름"`. 상한 `MAX_HASH_CHARS` 는 고정식이고 `urlState.test` 가 잰다. 꺼진 CSP 의 링크는 자유 입력 셋과 `env` 만 살리고 지역 · 선택을 버린 뒤 한 줄로 알린다
- **트리 행 = catalog 행** (D53 · `selection.ts` · `ResourceTree.tsx`) — 규칙이 둘 이상인 행은 범위를 먼저 고르고, 종류는 범위의 `allowed` 로 다시 거른다. 존이 없으면 존 행은 새로 체크할 수 없다(이미 고른 행은 남기고 FAIL 카드로 이유를 보인다)
- **소개 예시** (D107) — 마법사 소개 상자의 이름은 `introExamples.json` 에서 읽는다. 그 파일은 빌드마다 `scripts/gen-intro-examples.mjs` 가 `introExampleModel.ts`(마법사와 같은 길)로 엔진을 불러 쓴다. 커밋된 파일이 엔진 결과와 다르거나 하나라도 `valid: true` 가 아니면 `introExamples.test.ts` 가 실패한다. 화면은 스스로 이름을 짓지 않는다
- **첫 방문 예시** (D108 · `wizardSample.ts`) — hash 가 없으면 `samplePlan()`(예시 값 넷 · 네트워크 미리 채움 · `addBundle` 로 더한 `serverless-web` 카드)으로 시작하고, 소개 예시도 같은 계획에서 뽑는다. `/aws` 는 `samplePlan('aws')` — AWS 예시 값과 `website` 카드(D141), 이름 15개다. `Wizard.tsx` 의 `sample` 상태가 켜진 동안은 hash · Share URL · Save plan 이 없고 Project 칸에 **Example** 과 **Clear**(D97 의 `startPlan()` 으로)가 보인다. 무엇이든 바꾸면 꺼진다. `wizardSample.test.ts` 가 이름 전부 `valid: true` 를 본다
- **이름 막대** (D108) — 태블릿 · 폰만. 아래 고정 막대가 이름 드로어(태블릿) · Names 탭(폰)을 열고, 그것이 보이는 동안은 숨는다. 폰은 짧은 글 *View N names* 다(D109). `aria-label` 은 늘 긴 글 + PASS 수다
- **About 쪽** (D109 · `About.tsx` · `aboutModel.ts`) — `DocPage` 틀의 `/about`. 소개의 `IntroExample` · 이름 칸과 같은 `pass_meaning` · `wizard_nothing_created` 문장 · 소스 저장소 링크(`SOURCE_REPOSITORY_URL` — URL 을 적는 유일한 자리) · 라이선스 · 상태 · `VERSION`. More 메뉴의 About 은 이 쪽 링크(`aboutHref`)이고, `DocPage` · `App` · `Wizard` 푸터도 Privacy 옆에 건다
- 화면 문구는 `src/messages/en.ts` 에서만 온다 — `no-hangul.test.ts` 가 리터럴 · JSX 글자를 센다
