# 규칙 표 공식 문서 대조

`src/core/constraints.ts` 의 `RULES` 35개(처음 24개 + 2026-10-06 에 더한 11개 — 아래 「2026-10-06 추가 11종」)와 `LABEL_LIMITS` 3개를 각 `docUrl` 의 CSP 공식 문서와 맞춰 본 기록이다. 2026-09-28 에 URL 을 `curl -sL` 로 받아 태그를 벗기고 해당 문단을 찾았으며, 앵커는 받은 HTML 의 `id` 로 확인했다.

## 읽는 법

네 칸은 ⑴ 길이 ⑵ 허용 문자 · pattern ⑶ 시작 · 끝 ⑷ 예약어 · 금지 접두 · 접미다.

| 표시 | 뜻 |
|---|---|
| 일치 | 코드 값이 문서와 같다 |
| 불일치 → 고침 | 문서와 달라 코드를 고쳤다. [decisions.md](decisions.md) 에 적었다 |
| 보수적 | 코드가 문서보다 엄격하다. 유효한 이름을 거부할 수는 있으나 무효를 유효로 표시하지는 않는다 — 그대로 두고 [decisions.md](decisions.md) 에 적었다 |
| 해당 없음 | 문서에 그 종류의 규칙이 없고 코드도 두지 않았다 |

**결과 한 줄** — 문서 근거가 없는 규칙은 **0개**(뺀 규칙 없음) · 값 고침 **3개** · `docUrl` 고침 **4개**(+ 앵커 · 도메인 정리) · 보수적 한도 유지 **4개**. 개발 1단계 마감 뒤 **보수적 한도 3개를 더했다**(GCS 연속 점 `..` 금지 · Azure 리소스 그룹 보조 평면 문자 거부 · Azure VM 점 전부 거부 — 2026-09-28 1단계 고침, 근거는 [decisions.md](decisions.md)).

## Azure 예약어 (2026-09-29 추가)

근거: https://learn.microsoft.com/en-us/azure/azure-resource-manager/troubleshooting/error-reserved-resource-name — "Resources with an accessible endpoint, such as a fully qualified domain name, can't use reserved words or trademarks in the name." 이름 규칙 쪽(`resource-name-rules`)에도 "Resources with a public endpoint can't include reserved words or trademarks in the name." 가 있다. 위 대조 표의 ⑷ 는 이 문서를 보기 전의 판정이라, 아래 규칙에서는 이 절이 ⑷ 를 대신한다.

| 문서 | 코드 (`AZURE_RESERVED`) |
|---|---|
| ACCESS … XBOX 38개 — 단어로 금지 | `forbidden.words` — 앞뒤가 영문 글자가 아니면(숫자 · 기호 · 이름 끝) 단어로 본다. **보수적** — 문서가 「단어」를 정의하지 않는다 |
| MICROSOFT · WINDOWS — 단어 · 부분 문자열 모두 금지 | `forbidden.contains` |
| LOGIN — 앞에서만 금지 | `forbidden.prefixes` |
| 목록이 대문자 | `forbidden.ignoreCase` — 대소문자를 가리지 않는다 |

| 규칙 | 적용 | 이유 |
|---|---|---|
| `azure.storage_account` · `azure.key_vault` · `azure.sql_server` | 건다 | 공개 FQDN 이 있다 (`*.core.windows.net` · `*.vault.azure.net` · `*.database.windows.net`) |
